# Clinic Appointment Scheduler

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)
![SQLite](https://img.shields.io/badge/SQLite-003B57?logo=sqlite&logoColor=white)

**Clinical appointment scheduling system in Python** — patients, doctors and appointment slots managed through a modular MVC-style structure (`modulos/`, `controladores.py`) with SQLite persistence.

## Getting Started

```bash
python init_db.py   # create the database
python main.py      # run the app
```
